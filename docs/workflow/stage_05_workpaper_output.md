# Stage 5 — Workpaper, calculators and output

## Purpose

`v1/workpaper_builder.py`, the versioned `tax_calculators/` package and the
writer create the review workbook and deterministic reconciliation.

## Inputs and outputs

- Input: labelled reports, decision traces, approved configuration and reviewed
  calculator facts.
- Output: Excel workpaper plus completed `WorkpaperResult`.

## Debug procedure

1. Verify `result.json` says `completed` before trusting an Excel output.
2. Reconcile source periods and confirm that only approved adjustments post.
3. Run calculator tests plus `python -m unittest tests.test_end_to_end -v`.
4. Never repair totals or select a tax rate silently to make the workbook look
   complete.

## External workflow references

- [ATO Company tax return instructions — reconciliation to taxable income or loss](https://www.ato.gov.au/api/public/content/0-e220713e-6a6f-4401-b966-8bddf3ba96fd)
  — current-year Item 7 instructions, including the accounting R&D expenditure
  add-back at D and deduction for decline in value at F.
- [ATO Research and development tax incentive schedule 2025](https://www.ato.gov.au/api/public/content/0-3aecc6a6-76b2-4302-b00c-a2d8e6443fb2)
  — the R&D schedule is required when claiming a refundable or non-refundable
  R&D offset at Item 21; do not create a generic R&D form for an ordinary
  company workpaper.
- [ATO Worksheet 2 — other reconciliation items](https://www.ato.gov.au/forms-and-instructions/company-tax-return-2022-instructions/worksheet-2-other-reconciliation-items?anchor=note6)
  — Worksheet 2 assists the Item 6T-to-7T reconciliation and is not an
  exhaustive or universally required list of adjustments.

Use the source page matching the selected income year before changing any
versioned rule. These references define filing workflow, not a substitute for
the evidence and accountant approval required by this application.
